# Microgrid DRL Project

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/VARUNMAVURI/Microgird-OS)

A Deep Reinforcement Learning project for Smart Microgrid Energy Management.

## Structure
- `/backend`: Flask server, database manager, and simulation engine.
- `/frontend`: User interface templates and static assets.

## Getting Started
1. Install dependencies.
2. Run the backend server.
3. Access the dashboard.
